This is the only part of OpenEXR that nanoOCP ships. FreeImage is built with BUILD_OPENEXR=OFF, but
Source/OpenEXR/Half is added to its CMake target unconditionally -- FreeImage's own half-float pixel type
(FIT_RGBAF16) needs it -- so one object, half.cpp.o, is compiled into libFreeImage. The EXR codec itself is not.

above in Source/OpenEXR/Half/half.cpp; it ships no LICENSE file for OpenEXR. The full BSD-3-Clause text as the
OpenEXR project publishes it should be pasted in here before this wheel is distributed publicly:
