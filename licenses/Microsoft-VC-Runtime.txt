What it is
----------
msvcp140.dll is the Microsoft Visual C++ 14.x standard C++ library runtime, which
nanocct's extension modules and the bundled OCCT libraries need. It is included so
that nanocct works on Windows installations that lack the Microsoft Visual C++
Redistributable; Windows itself does not ship it.

Provenance
----------
- Source: the Visual C++ runtime folder of the Visual Studio 2026 installation that
  builds the wheel, VC\Redist\MSVC\<version>\x64\Microsoft.VC145.CRT, where <version>
  is the one VC\Auxiliary\Build\Microsoft.VCRedistVersion.default.txt names
  (deps/vc-redist-crt.sh in nanocct's source).
- Modification: none. The file in the wheel is byte-for-byte identical to that
  Microsoft original and keeps its Microsoft Authenticode signature: the build checks
  its SHA-256 against the original (tools/check_vc_runtime.py). The wheel-repair tool
  delvewheel only adds a content-hash suffix to the file name and updates the
  references to it in the files that load it.
